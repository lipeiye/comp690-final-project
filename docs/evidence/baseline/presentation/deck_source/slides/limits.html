What these results do not show

Nine people, one dataset

Wide intervals; no claim for new users, headsets or implants.

Desktop timing

Not microcontroller latency, SRAM or energy.

Pruning confound

Pruned models got 100 extra fine-tuning epochs.

Per-person electrodes

A headset would need one fixed set for everyone.

One redundancy measure

Band-power correlation only; others may differ.

Offline replay

No closed-loop or asynchronous use was tested.

I want to be explicit about the claim boundaries. With nine participants the bootstrap intervals are exploratory. All timing is from a desktop CPU, so it says nothing direct about a microcontroller. The pruned models had extra training, which muddies the pruning comparison. And electrodes were chosen separately for each person, while a real headset has one fixed layout.
