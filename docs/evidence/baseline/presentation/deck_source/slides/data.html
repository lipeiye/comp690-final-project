Peiye Li · COMP 690 · 4

The test day is locked in code: the loader for session 2 refuses to run unless called by the final evaluation, and that script refuses to start until the frozen plan file exists. Every number on the result slides comes from that single pass over day 2. Trials that experts flagged as artifacts are excluded in the primary analysis; a secondary analysis keeps them.
